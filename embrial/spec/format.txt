Introduction:
    Welcome to the Embrial programming language. Ebl for short. Ebl is a
    a statically, typed low-level programing language, designed around an
    easy-to-read syntax that provides expressive, explicit, and memory-safe
    code. Lux's type system controls data, through types, allocators, ownership
    and borrowing through references. Lang treats the command line interface,
    allocators, result types, optionals, and errors as first class citizens. Lux
    is intended to be used for both general and systems programming, favouring
    simple rules, predictable behaviour, and a small set of composable
    primatives.

Notation:
    The syntax is specified using a variant of Backus-Naur form.

    #block embrial/spec/notation.txt

    Productions are expression constructed from terms and alternation operators
    '|'. Terminals can be symbol, keyword, or one of the 5 basic classification
    EPSIOLON, EOF, ID, and NUM which refers to the once declared in the grammar.
    Symbols are any single charachter that are non alhpa numeric. Keywords are
    the set of all identifiers such as "name" defined in the grammar.

Comments:
    Comments are used to document programs. Embrial programs are self
    documenting based on where comment occur. Embrial has a single form of
    comment, begining with a hashtag '#', followed by an arbitrary sequence of
    charachters, ending with a newline charachter '\n'.

    #block embrial/spec/comments.txt

    Comments may occur only at the end of a line. Nested comments are impossible
    considering that every charachter between the first '#' on a line, until the
    newline at the end of the line is comment, meaning that any '#' enclosed in
    that region is a commented charachter.

    A block comment is considered to be 1 or more comments that are writen
    sequentially with only whitespace between comments. Comments on sequential
    lines are logically concatonated by striping leading whitespace of every
    line of the block comment then concatonating. Bellow are two equivalent
    comments,

    #block

    Note that the whitespace at the end of a comment is not trimmed. The first
    above comment ends with a single space charachter. Escape sequence are also
    processed,

    #block

    When printed would display as,
    comment with
    a newline
