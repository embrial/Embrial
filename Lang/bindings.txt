Bindings and ownership model:
    A binding is an association between a name, and a semantic property of that
    name. In lang data associated with a name is refered to as a binding. A
    variable is a binding between a name and mutable data of a given type,
    whereas a constant is a binding between a bane abd imutable data of a given
    type. To declare a binding, list the mutability, then name, then an optional
    type, followed by an assignment of an initial value.

      1 |   var x i32 = 0;              #  mutable binding
      2 |   const PI f64 = 3.1415926;   # imutable binding

    Variables may be assigned new values at any time, whereas constants may only
    be assigned a value once.

      3 |   x = 1;         # x can be assigned a new value
      4 |   PI = 3.14;      # PI cannot be assigned a new value

    In Lang, data must have exactly one owner at a given time. Types written as
    `T` copy their data when assigning one binding to another. To indicate that
    a binding owns its data, prefix the type with `@`. Assignment behaviour is
    shown in the table below,

    assignment behavior | from non-owned (`T`) | from owned (`@T`)
    --------------------|----------------------|------------------
    to non-owned (`T`)  | copy                 | copy
    to owned (`@T`)     | copy                 | move

      1 |   var x1 u32 = 0;
      2 |   var x2 u32 = 1;
      3 |   var x3 @u32 = 2;
      4 |   var x4 @u32 = 3;
      5 |
      6 |   x2 = x1;   # copy x1 to x2
      7 |   x1 = x3;   # copy the value of x3 to x1
      8 |   x3 = x2;   # copy the value of x2 to x3
      9 |   x4 = x3;   # move x3 to x4, invalidating x3

    A copy creates an independent value, while a move transfers ownership of the
    data from the source binding to the destination binding. After a move, the
    source binding is invalid until it is assigned a new value.
